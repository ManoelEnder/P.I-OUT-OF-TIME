# Roteiro de teste manual (para o autor)

Os testes automáticos (`Ferramentas › QA`) cobrem o funcionamento. Este roteiro cobre o que só dá para julgar jogando. Use a build de release: `PROJETO TORRADEIRA/Builds/Windows/OutOfTime.exe` (gerada por `Ferramentas › QA › Build de release`).

1. **Abertura:** o aviso de fotossensibilidade aparece; [F] desliga os flashes; ENTER continua; tecla qualquer leva ao menu.
2. **Leitura:** em 1920x1080, o HUD, a mira e os textos estão nítidos; a imagem do cenário está pixelada (pixel 2x2) e com pontilhado.
3. **Mouse:** a sensação do mouse está boa nas quatro direções, com o visor fechado e aberto (C); o cursor fica travado no jogo e livre no menu/pausa/derrota/final.
4. **Leitura no escuro:** dá para achar as portas pelas luminárias; as peças temporais, quando reveladas pela foto, se destacam do cinza.
5. **Vermelho só para perigo:** a barra de calor é vermelha, a bateria é branca; o inimigo aparece a olho nu.
6. **Flashes desligados** (Configurações › FLASHES): as fotos não clareiam a tela e o brilho das peças fica fixo, sem pulsar.
7. **Fim:** depois das missões, a tela final aparece na sala do laboratório; MENU volta ao menu e CRÉDITOS abre os créditos.
8. **Fitas de isolamento:** continuam com o autor (pacote `ThirdParty/CautionTape` preservado).

Anote qualquer quadro travando (tela congela por um instante) e onde aconteceu.
